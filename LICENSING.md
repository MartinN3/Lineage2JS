# Licensing status

This fork derives from [realratchet/Lineage2JS](https://github.com/realratchet/Lineage2JS). Its inherited `package.json` declares `"license": "ISC"` and `"author": "Ratchet"`.

The upstream `stable` branch checked on 15 November 2026 contains that ISC declaration but no root `LICENSE` file with the full permission and copyright notice. The declaration is recorded here as evidence of upstream metadata; the applicable copyright notices and scope of the license still need to be confirmed with the upstream author.

Before adding a complete `LICENSE` file or considering a license change:

- Confirm the upstream ISC declaration and obtain the applicable copyright and permission notice from the upstream author.
- Preserve the required notices for upstream code and any other third-party material.
- Verify ownership and permissions for the work covered by any proposed license change.

This documentation does not relicense the existing code or replace any applicable third-party terms. The inherited ISC metadata remains unchanged. No MIT license is introduced by this change.

[PHILOSOPHY.md](PHILOSOPHY.md) states this fork's preservation and fair-play principles. It is not an additional license condition. Game assets and dependencies remain subject to their respective rights and terms.
